# Student Record System

## Project Description
The Student Record System is a simple Java file handling project developed to demonstrate reading and writing data using FileReader and FileWriter. 
The program allows users to enter student details such as name and marks, stores the information in a text file, and then 
reads the stored data from the file for display.

This project also demonstrates basic exception handling using try-catch blocks to manage file related errors efficiently.

## Features
- Accepts student details from the user
- Writes data into a text file
- Reads data from the text file
- Displays stored student records
- Uses exception handling for safe file operations

## Technologies Used
- Java
- FileReader
- FileWriter
- Exception Handling
- Git & GitHub

## How to Run
1. Compile the Java file
2. Run the program
3. Enter student details
4. View stored records from the file
